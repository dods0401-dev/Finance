# Checklists

## Pre-market (before 09:30 NY / 15:30 Italy)
- [ ] Economic calendar: any CPI / Fed / jobs data today? Earnings of watched stocks?
- [ ] `/trader-scanner daily` + `/trader-news` on the watchlist
- [ ] Today's state: losses in a row, risk used today, drawdown brake on or off?
- [ ] Max 3 candidates. Liquid stocks only (tight spread, high volume).

## Pre-entry (before asking for "yes")
- [ ] Setup matches a known pattern (scanner/entry), not a hunch or FOMO
- [ ] Stop and target set, reward:risk >= 1.5
- [ ] Loss at stop <= $120 (or $60 with the drawdown brake)
- [ ] Daily: under 20 trades (5 open at once), under $240 risk used, not after 5 losses in a row
- [ ] Inside 09:45–15:30 NY, not earnings day, not right after a macro release
- [ ] Time Machine verdict read and shown
- [ ] `/trader-risk` PASS

## Post-trade (after exit)
- [ ] Result in R (e.g. +1.0R, -1R)
- [ ] Did I follow the plan? (entry, stop not moved, exit on plan)
- [ ] One lesson, one sentence → journal
- [ ] Weekly: `/trader-journal review` — win rate, average R, rule breaks
